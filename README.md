# Tornado-Box-Solidworks

SolidWorks CAD models for a laboratory tornado simulation apparatus, designed based on CM1 numerical simulation outputs of tornado boundary layer flow.

## Repository Structure

├── Tornado Air control/       # Air flow control components
├── Tornado Accessories/       # Accessory parts
├── Tornado frame and box/     # Main frame and enclosure structure
└── Tornado overall.SLDASM     # Top-level assembly file

## Hardware Overview

This repository contains the mechanical design files for a physical tornado simulator box, including:
- Air inlet and flow control system
- Supporting frame and enclosure
- Accessory components and mounts

## File Formats

| Extension | Description |
|---|---|
| `.SLDASM` | SolidWorks Assembly file |
| `.SLDPRT` | SolidWorks Part file |

## Requirements

- SolidWorks 2022 or later recommended

## Simulation Data Reference

The design of this apparatus is informed by idealized tornado simulations. The reference dataset used in this project is publicly available at:

> Wang et al. (2020), *Idealized Tornado Simulations — Turbulence Memory Study*
> [Penn State Data Commons](https://www.datacommons.psu.edu/download/meteorology/wang-et-al-idealized-tornado-simulations-turbulence-memory-study-2020/)

## Related Research

This apparatus is designed to support tornado vortex structure research using CM1 model simulation data.
